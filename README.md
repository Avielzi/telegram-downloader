## ⚡ Quick Start

### Prerequisites
- **OS**: Windows 10/11
- **Python**: 3.10 or higher
- **Credentials**: Telegram API `api_id` and `api_hash` (Get them at [my.telegram.org](https://my.telegram.org))

### Installation & Launch

```bash
# 1. Clone the repository
git clone https://github.com/Avielzi/telegram-downloader.git
cd telegram-downloader

# 2. Install dependencies (Windows)
install.bat

# 3. Launch the application
run.bat
```

---

## 🖥️ Usage Workflow

1.  **Authentication**: Launch the app and enter your phone number + 2FA code (required only once).
2.  **Source Selection**: Paste the link to any Telegram group or channel.
3.  **Scan**: Click "Scan" to index all available media.
4.  **Filter**: Use the search bar and type filters to find specific content.
5.  **Download**: Select your files and hit "Download". Your media will be saved to your specified output folder.

### Supported Media Types
- 🖼️ **Images**: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`
- 🎬 **Videos**: `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`
- 📄 **Documents**: `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.txt`
- 🗜️ **Archives**: `.zip`, `.rar`, `.7z`, `.tar.gz`

## ⚙️ Configuration

A `config.json` file is automatically generated on the first run. You can customize your experience here:

```json
{
  "api_id": 123456,
  "api_hash": "your_api_hash_here",
  "download_path": "C:/Downloads/Telegram",
  "language": "he",
  "dark_mode": true,
  "parallel_workers": 3,
  "resume_enabled": true
}
```
