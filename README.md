# Telegram Downloader

High-performance Telegram media downloader with a PyQt6 desktop interface.

Download images, videos, documents and other media from Telegram channels and groups.

---

## ⭐ Features

- Parallel media downloads
- Smart resume for interrupted downloads
- Deep media scanning
- Dark mode UI
- English + Hebrew interface
- Secure local session storage

# English

## 🚀 Quick Start

### 1. Clone repository

git clone https://github.com/Avielzi/telegram-downloader.git  
cd telegram-downloader

### 2. Install dependencies

pip install -r requirements.txt

### 3. Run application

python telegram_downloader.py

---

## ⚙️ Requirements

Python 3.10+  
PyQt6  
Telethon
